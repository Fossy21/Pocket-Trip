# NORTHERN ESCAPE ’27 — Pocket Trip

Family trip, 21–25 January 2027. Based on the supplied V8 HTML.

## Files
- `index.html`: all 39 itinerary rows, 5 days, 4 nights, room names, travel and budget. Edit the HTML directly; it works without JavaScript.
- `styles.css`: responsive styles and print layout.
- `app.js`: print button, current-day indicator and image failure handling only.
- `*.webp`: self-hosted imagery. 15 distinct AI illustrations and 2 licensed photographs.
- `image-manifest.json`: AI image provenance and concise prompt specifications.
- `PHOTO-CREDITS.md`: photographic licenses and attribution.

## Publish
Upload these files into the repository root. GitHub Settings → Pages → Deploy from a branch → main → /(root). HTTPS URL: https://fossy21.github.io/Pocket-Trip/ (verify after deployment).

## Planning status
Flight times, room types and prices are planning assumptions from V8, not confirmed bookings. Optional stops can be skipped. No personal booking references or private contact details are included.

Hotel images are linked to their original providers rather than copied without a reuse license. AI illustrations are clearly identified and do not depict actual hotel rooms.
